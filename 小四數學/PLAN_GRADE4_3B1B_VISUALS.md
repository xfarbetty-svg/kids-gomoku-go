# 國小四年級數學 3B1B 動態幾何與抽象量感透視系統規格書 (PLAN_GRADE4_3B1B_VISUALS)

> **核心指導準則**：以 3Blue1Brown (Grant Sanderson) 的連續幾何形變與物理直覺，將台灣 108 課綱國小四年級 23 大主題（506 題）全量視覺化。  
> 堅持純原生 HTML5 Canvas 60fps 渲染，零外部程式庫相依，零雲端 Token 消耗，離線秒開，極致流暢。

- **檔案結構**：
