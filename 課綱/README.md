# 台灣國中小學習資源與官方課綱核心指引

> **★ 開發鐵律（課綱先行原則）**：  
> 所有學科與全年級課程開發，在設計題目、劃分王國與編寫微步階引擎前，**一律必須先參照本資料夾內的官方課綱標準**，嚴禁憑空猜測難度或跨年級超綱出題。

---

## 🌐 官方資源平台來源

- **平台名稱**：教育部國民中小學課程與教學資源整合平臺（PRIORI 學習教材資源庫）
- **官方網址**：https://priori.moe.gov.tw/resource/material/
- **主要用途**：
  - 查詢並下載各年級、各學科（數學、自然、國語文、英語等）最新 108 課綱能力指標、單元節奏與學習節點。
  - 開發新教材或題庫擴充時，優先至此平台檢索公版教學指引與評量範例。

---

## 📂 本地現存課綱檔案清單

1. `105-1年級數學.pdf`：國小一年級數學領域課程手冊與核心素養學習重點
2. `105-5年級數學.pdf`：國小五年級數學領域課程手冊與核心素養學習重點
3. `105-6年級數學.pdf`：國小六年級數學領域課程手冊與核心素養學習重點

---

## 🔍 開發流程檢核 SOP

1. **查閱指標**：開發新關卡前，先開啟對應年級的 PDF 檔案，確認目標學習單元之學習表現與學習內容代碼（例如 N-1-1, S-5-2）。
2. **界定紅線**：明確抓出該年級的「範圍上限」與「嚴禁出現項目」（例如小一禁出現負數、小數、乘除直式；小五禁出現未知數方程式等）。
3. **題庫生成與守門員**：將課綱編號與定義餵入 125B 作為第一道 System Prompt，並由 Python 守門員腳本強制驗收 Exit Code 0。
