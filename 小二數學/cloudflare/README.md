# Cloudflare Pages

This app is a static Pages site. Set the Pages project root to `小二數學/app`
or deploy from the repository root with the output directory `小二數學/app`.

- Build command: none
- Output directory: `小二數學/app`
- Entry point: `index.html`
- No API key or server-side secret is required.
- The Ziyou crawler is a local-only authoring tool and is not deployed.

Before replacing the seed bank, run `python -X utf8 validate_grade2.py` and
have the read-only curriculum auditor review the downloaded Ziyou material.
