# 台灣 108 課綱 國小二年級數學領域標準規範

> **核心準則**：此規範為「國小二年級數學教學與題庫 APP」之最高指導依據。  
> 任何題庫生成、題目過濾、AI 軍師提示生成，**皆必須嚴格遵守此課綱範圍，嚴禁超綱或降綱**。

## 📌 108 課綱四大主題與核心條目

### 一、數與量（N）

| 條目 | 主題 | 說明 |
|------|------|------|
| 2-n-01 | 1000以內數與位值 | 命名、說讀聽寫、百位位名、位值單位換算（幾百幾十幾 ↔ 幾個百幾個十幾個一） |
| 2-n-02 | 錢幣換算 | 認識100元、10元與100元換算、點數錢幣合起來多少、付款 |
| 2-n-03 | 大小比較與遞移律 | 用＜、＝、＞表示大小關係、具體情境中認識遞移律 |
| 2-n-04 | 二位數加減直式 | 熟練二位數加減直式（含進位退位） |
| 2-n-05 | 三位數加減直式 | 理解三位數加減直式（不含兩次退位；可含兩次進位；100減一位或二位數） |
| 2-n-06 | 乘法意義 | 從連加理解乘法、用×、＝做橫式紀錄、解決生活中的問題 |
| 2-n-07 | 分裝與平分 | 具體情境中分裝與平分（**不引入除法算式、不引入餘數**） |
| 2-n-08 | 九九乘法 | 理解九九乘法中前後項關係、熟記九九乘法 |
| 2-n-09 | 兩步驟問題（加減） | 連加、連減、先加後減或先減後加（**不含併式**） |
| 2-n-10 | 兩步驟問題（加減乘） | 先加(減)後乘、先乘後加(減)（**不含併式**） |

### 二、空間與形狀（S）

| 條目 | 主題 | 說明 |
|------|------|------|
| 2-sc-01 | 平面與立體圖形 | 認識簡單平面圖形的角與邊、立體形體的頂點邊面、正方體特徵 |
| 2-sc-02 | 平行與垂直 | 生活周遭中平行與垂直的現象（不下定義） |
| 2-sc-03 | 直尺與線段 | 使用直尺畫給定長度線段、測量兩點距離（限公分，不超15cm） |
| 2-sc-04 | 面積認識 | 面積直接比較、間接比較、個別單位比較（**限正方形或長方形為單位，不引入「面積」名詞**） |
| 2-sc-05 | 平面圖形邊長關係 | 正方形四邊等長、長方形兩雙對邊等長、正三角形三邊等長、等腰三角形兩腰等長 |

### 三、關係與應用（A / N）

| 條目 | 主題 | 說明 |
|------|------|------|
| 2-a-01 | 大小比較與遞移律 | 同2-n-03（代數領域重複） |
| 2-a-02 | 加法交換律與結合律 | 加法順序改變不影響和，簡化計算 |
| 2-a-03 | 乘法交換律 | 排列模型中認識 a×b＝b×a |
| 2-a-04 | 加減互逆 | 理解加減互逆、運用於驗算與解題、比較型減法、算式填充 |
| 2-n-15 | 長度單位 | 公分、公尺、1公尺＝100公分、同單位加減計算、實測估測 |

### 四、其他（感官量）

| 條目 | 主題 | 說明 |
|------|------|------|
| 2-n-12 | 鐘面時刻 | 幾點幾分、整點至整點經過時間、12時制 |
| 2-n-13 | 時間單位 | 年、月、星期、日、平閏年認識（**限查月曆情境，不引入算式**） |
| 2-n-14 | 測量單位數值 | 用不同個別單位測量同一長度，數值不同及原因 |
| 2-n-16 | 容量 | 直接、間接與個別單位比較（**不引入公升/毫升**） |
| 2-n-17 | 重量 | 直接、間接與個別單位比較（**不引入公斤/公克**） |

## 🛡️ APP 開發與題庫生成之「課綱守門員守則」

### 絕對禁止（超綱）
1. **除法算式**：不引入「÷」符號、不引入餘數（2-n-07 僅分裝/平分活動）
2. **「面積」名詞**：二年級不引入此名詞（三年級才引入）
3. **公斤/公克/公升/毫升**：二年級只做比較（三年級才引入常用單位）
4. **公尺公分混合運算**：只做同單位計算，不做 m-cm 化聚
5. **兩次退位減法**：2-n-05 明確排除「其它整百減二位數」如 200-23
6. **負數**：嚴禁出現
7. **未知數 x 移項**：小四僅能用 □ 或括號
8. **兩位以上乘數**：乘法應用題乘數最大為 3（2-n-06 教學建議）
9. **大於1000的數**：2-n-01 限制在1000以內
10. **併式記錄**：2-n-09/2-n-10 限制用兩個算式，不引入併式
11. **「乘法交換律」「加法交換律」「加減互逆」名詞**：不宜出現在教學與評量中
12. **「對邊、鄰邊、腰」等名詞**：2-sc-05 不宜出現在教學與評量中

### 嚴格要求
1. 所有數值在 1～1000 範圍內
2. 錢幣題目僅使用 1, 5, 10, 50, 100 元
3. 時間題目限 12 時制
4. 乘法題目僅限 1～9 範圍（九九乘法）
5. 分裝/平分題目答案必須整除（無餘數）
6. 三位數加法可含兩次進位，但減法不可含兩次退位
7. 答案與選項必須為整數
